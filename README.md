## 📝 Descripción

**Bedrock Utils** es una colección de soluciones y recursos útiles para desarrolladores y creadores de Minecraft Bedrock Edition. Incluye scripts en JavaScript, archivos JSON, glifos personalizados y más, pensados para facilitar y potenciar tus proyectos dentro del ecosistema Bedrock.

---

## ✨ Características

- 🚀 Scripts y utilidades listos para usar
- 📄 Archivos JSON configurables para entidades y recursos
- 🔤 Glifos personalizados y texturas integrables
- 💡 Ejemplos prácticos y documentación comentada
- 🧑‍💻 Fácil integración en proyectos existentes

## ▶️ Uso

Puedes adaptar los scripts o archivos JSON en tus propios mundos o addons de Minecraft Bedrock Edition. Los archivos se organizan en carpetas según su funcionalidad:

```plaintext
bedrock-utils/
├── scripts/
│   └── example-script.js
├── resources/
│   └── example-resource.json
├── glyphs/
│   └── custom-glyph.png
```

### Ejemplo de uso en un script

```js
import { ExampleUtil } from './scripts/example-script.js';

ExampleUtil.run();
```
