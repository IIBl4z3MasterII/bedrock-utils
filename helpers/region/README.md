# 📐 Region

`Region` class — cuboid between two corners, with methods to know if a
point is inside, if it overlaps with another region, its center, volume,
and persistence asJSON.

## Why does it exist

It is the basic piece needed by systems such as a land-claim, a World Edit
or a safezone: instead of reimplementing "is this point within
these two corners?" in each script, the logic lives in one place,
instantiable and independent of any specific business system.

---

## Public API

| Method | Parameters | Returns | Description |
|---|---|---|---|
| `constructor(corner1, corner2,dimensionId?)` | `corner1, corner2: Vector3`, `dimensionId: string = "minecraft:overworld"` | `Region` | Normalize corners (doesn't matter the order you pass them in — calculates min/max only) |
| `contains(location,dimensionId?)` | `location: Vector3`, `dimensionId?: string` | `boolean` | `true` if the point is inside the cuboid. If you pass `dimensionId`, also validates that it matches |
| `overlaps(other)` | `other:Region` | `boolean` | `true` if two regions overlap (same X/Y/Z axis and same dimension) |
| `getCenter()` | — | `Vector3` | Center point of the cuboid |
| `getVolume()` | — | `number` | Volume in blocks (`width × height × depth`, inclusive) |
| `getCorners()` | — | `[Vector3, Vector3]` | The two normalized corners `[min, max]` |
| `toJSON()` | — | `string` | Serializes the region (to save to a Dynamic Property) |
| `Region.fromJSON(json)` *(static)* | `json:string` | `Region` | Rebuilds a `Region` from the string generated by `toJSON()` |

## Usage example

```js
import { Region } from "./helpers/region/index.js";

const claim = new Region(
    { x: 100, y: 0, z: 200 },
    { x: 150, y: 255, z: 250 },
    player.dimension.id
);

// Is the player inside their claim?
if (claim.contains(player.location, player.dimension.id)) {
    player.sendMessage("§aYou are inside your claim.");
}

// Does it overlap with an existing claim? (to block buying a new one)
if (claim.overlaps(otroClaimExistente)) {
    player.sendMessage("§cThis claim overlaps with an existing one.");
}

// Save in a Dynamic Property
world.setDynamicProperty("claim:player123", claim.toJSON());

// Retrieve it later
const saved = Region.fromJSON(world.getDynamicProperty("claim:player123"));
```

---

## Grades

- `contains()` and `overlaps()` are edge-inclusive (`>=`/`<=`),
non-exclusive — a point exactly on the limit counts as
"inside".
- `overlaps()` returns `false` input if the two regions are in
different dimensions — no need to check it separately.
- Designed to be combined with `WorldManager`/`DynamicStore` for
persist claims/zones between sessions (`toJSON`/`fromJSON` exist
just for that).
